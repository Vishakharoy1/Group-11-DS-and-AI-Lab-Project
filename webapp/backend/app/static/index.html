5. Model Comparison

Real-World Test Accuracy (Test Sample folder, 25 real + 25 fake images)

Measured by manually running every image in Test Sample/Test_real_vs_Fake/ through each model. Balanced Accuracy = average of Real-accuracy and Fake-accuracy — the fair way to compare models that may be biased toward one class.

ModelReal AccuracyFake AccuracyBalanced AccuracyBias
best76.0% (19/25)75.0% (12/16)75.5% None — errs roughly equally both ways
noaug40.0% (10/25)100.0% (16/16)70.0% Severe — defaults to "Fake" regardless of input
manipulations64.0% (16/25)68.8% (11/16)66.4% Mild — moderate accuracy both ways
cross_domain*64.3% (9/14)100.0% (9/9)82.1% Mild — leans toward "Fake" on non-face-domain images

"Fake Accuracy" excludes 9 numbered test files per folder found to likely be mislabeled real photos (all 3 models independently agreed they were Real). noaug's 100% fake-catch rate looks best in isolation, but comes from a severe bias toward predicting "Fake" — it wrongly flagged 15 of 25 genuine real photos, which is a worse real-world failure mode (false-accusation risk) than its headline number suggests. best has the highest balanced accuracy and no systematic bias.

* cross_domain was measured on a different, non-face image set (Test Sample/Cross Domain/, 14 real + 9 fake) — not directly comparable to the other three rows above, which were all measured on the same 25+25 face image set.
